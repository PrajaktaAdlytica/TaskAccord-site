TaskAccord design decisions (our proposals, not effects attributed to those websites)
- Original cotton rag / survey-paper texture: ivory quiet reading area, visible fibre detail, restrained sage and brass contours. New asset survey-paper-hero-v2.webp (~407 KB). Native HTML remains above it.
- Six workflow links use five staggered horizontal material slats, revealing behind unchanged text over about 420–560ms. Each has a distinct sage/clay/limestone/mushroom tint. Keyboard focus gets the same reveal. Coarse/touch layouts show the material without needing hover.
- Pricing cards use a restrained 3px lift, tobacco border, soft shadow and expanding top rule, with focus-within equivalence. Price and hypothesis labels never change.
- Hero record traces fixed facts with brief emphasis. Original diagram geometry is now inline SVG so connectors, attempted proposal, receipt milestones and invoice mismatch have specific controlled motion.
- Genuine prototype walkthrough changes among five actual screenshot captures, then holds at the mock mismatch. Direct selection pauses progression; Replay restarts. No generated UI screenshot or simulated evidence is passed off as a live product.
- Pause controls are shared across illustrative sequences. IntersectionObserver and document visibility stop work off-screen/hidden; media-query changes switch to a still view. All core labels and amounts remain readable. Reduced motion disables decorative transitions; hover is not required for information.
