# Joint buyer–supplier pilot experiment

Hypothesis: one already transacting API pair needs a shared task-level authority, scope, receipt and acceptance record beyond its current supplier agreement, procurement approvals and payment-provider evidence.

## Before outreach

Identify one operator, buyer and supplier; partnerships sponsor; procurement/legal owner on each side; budget owner; counsel owner; intended jurisdiction. Select exactly one of the five proposed modules for the first pilot. Keep the other four as separate offer tests.

## Sequence

Find an actual pair → interview both sides → review their existing task boundaries → counsel validates paper authority terms → both sides sign a pilot agreement defining ceiling, acceptance and disputes → manually rehearse one sandbox transaction → collect both parties' acceptance and exception requirements → evaluate repeat frequency, legal adoption and economics before engineering. Identify a settlement partner before contemplating real payments.

The website demo cannot satisfy any legal, payment or customer milestone in this sequence.

## Falsifiable gate

GO only when a real pair, jurisdiction clarity, counsel-reviewed authority and a dual-party signed pilot are evidenced, with a narrow repeated commercially viable workflow. If payments are contemplated, an identified settlement partner is also required. No pair, unclear authority/jurisdiction, no joint commitment or weak repetition means HOLD / STOP. Views, clicks, form drafts and synthetic exports do not meet the gate.

## Pricing hypotheses

$6,000 joint pilot; possible $2,000/month workflow SaaS only after repeated use is evidenced. Record explicit buyer feedback, scope, costs and willingness to pay. No transaction economics or revenue are assumed.

## Acquisition

Named API pairs through A2A integration partners, API marketplaces and procurement-tech alliances. Publish a mandate-control checklist. Avoid broad agent-economy campaigns or promises that agents sign contracts.

Only after a real pair and landing/form/consent QA: a hypothetical capped LinkedIn retargeting test of $150 per arm, mandate limits versus receipt auditability. Split buyer roles and pain framing, exclude existing contacts, use consistent UTM campaign/ad IDs and honor applicable platform/privacy requirements. Do not collect payments. Report spend, impressions, qualified visits, meetings and joint commitments, not CTR alone.
