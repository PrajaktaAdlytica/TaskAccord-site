**Recommendation:** Keep the ivory card and its price completely static. On devices that can hover, lift the card **2px over 160ms** and fade in a short brass dash in an empty corner. When a card’s CTA receives keyboard focus, show the dash **without moving the card**, and give the CTA its own visible dark-sage focus outline. This reads as gentle attention, not a selected plan or a purchase action. Use `:focus-within` for the card cue and `@media (hover: hover)` only for the pointer lift; neither pricing information nor the CTA should depend on hover. [MDN hover](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/hover) [MDN focus-within](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/:focus-within) [W3C Focus Visible](https://www.w3.org/TR/WCAG22/#focus-visible)[web:31][web:34][web:25]

```css
.plan {
  position: relative;
  transition: transform 160ms ease-out;
}
.plan::after {
  content: "";
  position: absolute;
  top: 1.25rem;
  right: 1.25rem;
  width: 1.5rem;
  height: 2px;
  background: #8b7046; /* decorative brass */
  opacity: 0;
  pointer-events: none;
  transition: opacity 160ms ease-out;
}
.plan:focus-within::after { opacity: 1; }
.plan .cta:focus-visible {
  outline: 2px solid #35483b;
  outline-offset: 3px;
}
@media (hover: hover) {
  .plan:hover::after { opacity: 1; }
}
@media (hover: hover) and (prefers-reduced-motion: no-preference) {
  .plan:hover { transform: translateY(-2px); }
}
@media (prefers-reduced-motion: reduce) {
  .plan, .plan::after { transition: none; }
}
```

Keep the price’s color, opacity, size, and position unchanged; keep the CTA visible and usable on touch. Test the actual sage outline against its adjacent ivory for **3:1 non-text contrast**, and price/body text for **4.5:1** (or **3:1** for large text). Explicit `transform` and `opacity` transitions avoid animating layout; reduced-motion users get the static cue.
